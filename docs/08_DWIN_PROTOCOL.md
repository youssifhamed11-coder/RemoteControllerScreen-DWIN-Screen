# 8) بروتوكول شاشة DWIN (DGUS II) — للمطورين

الإعدادات: 115200 baud، 8N1، من غير CRC (حسب `T5LCFG.CFG`).

## شكل الأوامر

```
5A A5 | LEN | CMD | ADDR_H ADDR_L | DATA...
LEN = عدد البايتات اللي بعد LEN (CMD + ADDR + DATA)
```

| الأمر | الوظيفة | مثال |
|---|---|---|
| `0x82` | كتابة في الذاكرة (VP) | `5A A5 05 82 00 84 5A 01 …` |
| `0x83` | قراية من الذاكرة | `5A A5 04 83 00 0F 01` بيقرا النسخة |

الرد على الكتابة: `5A A5 03 82 4F 4B` (يعني "OK").

## كتابة رسالة في الخانة (VP 0x2000)

ترميز GB2312: الحرف الإنجليزي بايت واحد، والحرف العربي بايتين (كود GB من `28_AR.HZK`). الرسالة بتنتهي بـ `FF FF`.

```
"Hello":   5A A5 0A 82 20 00 48 65 6C 6C 6F FF FF
           LEN = 1 (82) + 2 (2000) + 5 (حروف) + 2 (FFFF) = 0x0A
```

الـ ESP بيبعت دايمًا **160 بايت بالظبط تقريبًا**: الكلام مقسّم 32 عمود × 5 سطور، وفيه مسافات للتوسيط، وده بيحصل في `screen_text.h`.

## إعدادات الخانة على طول (SP 0x3000، يعني 13 كلمة)

| الكلمة | المحتوى |
|---|---|
| 0 | VP = `0x2000` |
| 1–2 | X,Y = 78,145 |
| 3 | اللون = `0x0000` (أسود) |
| 4–7 | المنطقة = 78,145 ← 722,367 |
| 8 | الطول = 160 |
| 9 | Font0_ID‖Font1_ID = `0x18 0x1C` (24‖28) |
| 10 | X_Dots‖Y_Dots = `0x28 0x28` (40‖40) |
| 11 | Encode‖HOR_Dis = `0x01 0x00` (GB2312) |
| 12 | VER_Dis‖0 = `0x00 0x00` |

```
5A A5 1D 82 30 00  20 00 00 4E 00 91 00 00 00 4E 00 91 02 D2 01 6F 00 A0 18 1C 28 28 01 00 00 00
```
